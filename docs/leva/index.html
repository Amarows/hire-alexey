        How this page was built
        
    The page is the work sample

    Division of labour
    Claude Code wrote the content, the questions for Jev, the prompts and this page. OpenAI Codex built the proxy, the matcher and the tests from written briefs. Every Codex diff was reviewed and its acceptance checks run before merge.
    
        
    Judgment, not arithmetic
    Plain code picks the evidence and the gaps. Jev only judges, and the page shows exactly what it was asked. Claude writes, cites cases, and does not invent numbers.
    
        
    Keys stay server-side
